tagline: Defining an AI tool for effortless, stunning presentations
overview:
  - Alai is a YC-backed (W24) AI powered presentation tool that helps tech professionals create high quality presentations faster.
  - They approached us to help build a fresh, innovative and intuitive v1 of the product — one that stands out from the sea of tools out in the market.
services:
  - Product Design for the entire platform – from the process of creating a presentation from scratch, to editing individual slides & elements, and the presentation interface.
  - AI UX strategy that ensures users get relevant output from Alai's AI and is intuitive to use.
  - UX & interaction design that's professional yet warm, familiar yet novel.
  - UI & design system that feels clean, fluid, dynamic and focussed.
  - Theming & canvas engine design that's flexible, robust and deceptively simple.

story:
  - kicker: The problem
    heading: Solving for the AI "blank start" paradox
    text:
      - Most AI tools promise magic, but require expertise to deliver well.
      - You probably already experienced what we mean — getting relevant, accurate output from AI the first time is not easy! It takes at least a few tries and iterations to understand what inputs to provide, how much context to give, and also calibrate your own expectations. By then, that "magical" feeling pretty much withers away.
      - We thought – how might we solve for creating a magical first time AI experience for Alai?
    notes:
      - { head: Excitement, body: "Fuelled by lofty promises on the website, users sign up with starry-eyed optimism." }
      - { head: Confusion, body: "Pushed into the deep-end with just a blank prompt field, users don't know where or how to begin." }
      - { head: Disappointment, body: "Users get a generic output because the prompt entered wasn't relevant or clear enough." }
      - { head: Acceptance, body: "Have to go through a bunch of iterations and learning curve to finally arrive at an acceptable output." }

  - kicker: Our solution
    heading: A fresh experience that smartly gathers the vital details from users, without feeling like a chore
    text:
      - We made getting started super simple & non-intimidating — just one big button to start generating with AI and additional options to DIY with layout.
    media:
      - { src: https://framerusercontent.com/assets/n35hESUqprbJ0ofuDm84us6OgEQ.webm, alt: "New presentation: one big Create With AI button" }

  - heading: Intuitive AI interactions, beyond "prompt-boxes"
    text:
      - While the prompt-box has become an AI UX staple, it's not always ideal. We identified instances where providing more specific, guided UX patterns would be better for both, the users and AI.
    notes:
      - { head: Threaded iterations, body: "We explored a new pattern for iterative items – threads. A simple yet clear way to let users know how their decisions are chained together, letting them go back & forth, and changing directions from anywhere in their thread." }
      - { head: Sliders, body: "We realised that certain aspects of presentations could be quantified as parameters on a scale. We introduced sliders for these, making their adjustment easy and visually intuitive for the user." }
      - { head: Select options, body: "The classic case of recognition vs. recall — users don't always know what to ask for. For certain parameters, we figured it was easiest to present clear, exhaustive options. This way, users can identify what they want, try it out and keep what works best." }
    media:
      - { src: https://framerusercontent.com/assets/Dr3mmq2pv0XXbzvVCSqI1GDCw.mp4, alt: "Threaded iterations: rewriting text with AI", shape: square }
      - { src: https://framerusercontent.com/assets/k2jW6VzjbhtRGMEeWHYd2SX7vbs.webm, alt: "A slider for velocity", shape: square }
      - { src: https://framerusercontent.com/assets/M7J4ZYp8G33Yz3UfMO92scIh6w.webm, alt: "Select options for tone", shape: square }

  - heading: Designing a flexible, robust canvas and theming engine
    text:
      - To have Alai's AI create beautiful, sophisticated presentations, we had to give it the right foundation to build on. We explored and crafted a deceptively simple system. It can add, scale & move elements, drastically change the vibe, smartly adapt content and much more, all while maintaining pristine aesthetics. How? That's a secret ;-)
    media:
      - { src: https://framerusercontent.com/assets/tsehPIuf5ke58I0PYGiIxpQtXws.webm, alt: "A slide building itself on the canvas" }

  - heading: Balancing customisability with ease-of-use
    text:
      - We benchmarked all existing presentation tools – decades-old and freshly-minted, to arrive at the edge Alai could offer users over all of them.
      - A theming system that offers a wide aesthetic range with just a few clicks.
    media:
      - { src: https://framerusercontent.com/assets/ULiy2DYbqkqOWBiveinktfhvyM.webm, alt: "One slide in several themes" }

  - heading: Creating element variants so they don't get repetitive and boring
    text:
      - Elements like content sections, tables, timelines, etc are usually used multiple times across slides. To make them look fresh and interesting every time, we created multiple variants of each one that users can shuffle between.

  - heading: All the small things
    text:
      - At Chariot, we take as much effort & pride in obsessing over the tiny details as we do the big picture stuff. Here are a few of the details on Alai that we're particularly proud of!
    notes:
      - { head: Informative visual affordances, body: "With our canvas following an effortless drag-and-drop structure, we crafted nifty, non-intrusive indicators to let the user know where they can drop elements to." }
