# Charioteer character sheet: 12 ready-to-paste prompts (v3)

Six Charioteers, two pictures each: **rest** (no orange) and **power** (one orange mark, shown on
hover on the site). Every prompt below is complete on its own: copy the whole paragraph into
ChatGPT image generation, nothing else to add.

## How to use

1. **Attach the person's current painting as a reference** with every prompt, so the face, hair, skin
   and costume stay theirs. The file is named under each person below (all in `public/media/people/`).
2. **Start with Aakash · power.** When it looks right, attach it as a second reference (for style) to
   the other eleven, so all twelve match.
3. Ask for **portrait 2:3**. If ChatGPT returns a square, say "make it 2:3 portrait, full figure".
4. Save as `<name>-rest.png` and `<name>-power.png` (aakash, joshua, samridhi, tanujaa, shreesh,
   siddharth) in `public/media/people/new/`. A plain white background is fine; I will cut them out.

## The idea, in five rules (already written into every prompt)

1. **Makers, not worshippers.** They use the tool, eyes on the work. Nobody looks up at it in awe.
2. **The bend.** Each body curves round its tool in one clear line.
3. **Two hands in one picture.** The person is painted the old way (egg tempera, wobbly ink line);
   the tool is drawn the new way (ruled lines, true perspective, real detail, cool matte greys). No
   gold, no glow, no shine.
4. **One orange mark, power pictures only:** a single flat Chariot-orange (#E0661B) construction line,
   like a designer's drawing. Nothing else orange.
5. **Paper, not parchment.** Plain white background, soft shadow at the feet. No frame, no lettering.

## Checking a result

- Is the tool the straightest, coolest, most exact thing in the picture? If it looks hand-painted
  like the clothes, regenerate.
- Any gold, glow or shine? Regenerate.
- Is the figure looking at the work, not up at the tool in awe?
- Exactly one orange mark in a power picture, none in a rest picture?
- Can the pose be read as one curve from across the room?
